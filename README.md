## 🛠 Что мы делаем

| Услуга | Что это |
|---|---|
| 🤖 **Telegram-боты** | Заявки, уведомления, рассылки, кнопки, меню, оплата. Заказы падают в таблицу. |
| 🕷 **Парсеры и скраперы** | Цены, товары, контакты, каталоги. Отдаём CSV, Excel, JSON или в базу. |
| ⚙️ **Автоматизация на Python** | Скрипты, интеграции с API, отчёты по расписанию, обработка файлов. |
| 🌐 **Сайты и лендинги** | Адаптивные, с формами и базовым SEO. Витрины и визитки под ваш бизнес. |
| 🧠 **AI-решения** | Чат-боты с ИИ, генерация картинок и текста, распознавание, авто-ответы. |
| 🛡 **Безопасность (white-hat)** | Проверка сайтов и кода, поиск уязвимостей и отчёт. Мы предупреждаем, а не атакуем. |

## 📬 Как с нами работать

1. **Задача** — присылаете описание. Честно говорим, наш это профиль или нет.
2. **Бесплатный мини-пример** — собираем демо по вашей задаче. Вы видите результат **до оплаты**.
3. **Оплата** — после того, как понравилось. Никаких предоплат вслепую.
4. **Отдаём код** — код + README + пояснения. Не «сырой скелет», а готовое решение.
